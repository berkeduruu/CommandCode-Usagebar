# CommandCode GOAT Usagebar — Türkçe kısa rehber

Cursor ve VS Code durum çubuğunda CommandCode GOAT kullanım kotasını, model/token kullanımını ve plan harcamasını gösterir.

## Kurulum

1. `Ctrl+Shift+P` veya `Cmd+Shift+P` tuşlarına basın.
2. **Extensions: Install from VSIX...** komutunu çalıştırın.
3. Projedeki `commandcode-goat-usagebar-0.1.7.vsix` dosyasını seçin.
4. Editörü yeniden yükleyin.

Kimlik bilgisi bulunamazsa **CommandCode Usagebar: Set API Key** komutunu çalıştırın. Session cookie ve API key hassastır; bunları kimseyle paylaşmayın. Ayrıntılı teknik belge için [ana README](../README.md) dosyasına bakın.
