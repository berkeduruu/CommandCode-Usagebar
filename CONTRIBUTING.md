# Contributing

Thanks for helping improve CommandCode GOAT Usagebar.

## Before opening a change

- Keep credentials, cookies, and account data out of commits and logs.
- Explain the user-facing problem and include a small reproduction when possible.
- Keep changes focused and preserve the existing command IDs and settings.

## Local checks

```bash
npm ci
npm test
npm run typecheck
npm run build
```

Pull requests should include a short summary, verification steps, and screenshots for dashboard UI changes.
